PPV Stream API Contract

Seluruh endpoint yang didaftarkan di src/main.rs dan src/federation, lengkap dengan autentikasi, bentuk request, dan bentuk respons. Disusun dari kode sumber, bukan dari spesifikasi terpisah.

Dasar

Konvensi

Autentikasi

Cookie ppv_session = b64url(sid).b64url(HMAC-SHA256). HttpOnly, SameSite=Lax, Secure di HTTPS. Login user membuat sesi non-admin; sesi admin hanya dari POST /admin/login.

Format error

Sebagian besar handler membalas HTTP 200 dengan {ok:false, error}, kadang plus where. Status 4xx/5xx asli hanya pada upload, streaming, dan federation. Klien wajib memeriksa ok.

Body

JSON kecuali disebut lain. Form login/daftar memakai application/x-www-form-urlencoded dan membalas redirect. Upload memakai multipart/form-data.

Label auth

publik tanpa login · user sesi valid · owner pemilik video · admin sesi admin · fed-admin header token · signature tanda tangan provider/HTTP.

// Respons sukses
{ "ok": true, ... }
// Respons gagal (HTTP 200)
{ "ok": false, "error": "not logged in" }
// Upload / validasi
{ "ok": false, "where": "validation", "error": "price_cents must be >= 0" }

Temuan keamanan dari review kontrak

Ditemukan saat menyusun dokumen ini. Nomor 1 sudah diperbaiki; sisanya belum diubah dan perlu diputuskan tim.

  1. Diperbaiki: /static_hls/* menyajikan HLS berbayar tanpa login. Kini nonaktif kecuali ENABLE_STATIC_HLS=1.
  2. POST /api/federation/follows/:id/reject tanpa autentikasi; siapa pun dapat membatalkan follow.
  3. Webhook tidak membandingkan jumlah yang dibayar dengan nilai invoice. Stripe tanpa toleransi timestamp (replay). PayPal ORDER.APPROVED dianggap lunas sebelum capture.
  4. Perbandingan secret tidak constant-time: token Xendit, signature Midtrans, Stripe, token federation admin, token bootstrap.
  5. Data pribadi: /api/creator/blocked_users menampilkan email; /api/allow memungkinkan cek email terdaftar; login admin membedakan not_admin; error Xendit memuat nomor rekening penuh; test_email masuk log.
  6. /api/pay/* dikecualikan dari CSRF guard padahal memakai cookie sesi; hanya bergantung pada SameSite=Lax. success_url/cancel_url tanpa allowlist.
  7. Error berisi pesan database mentah dan path server; /api/pay/providers publik menampilkan nama env yang belum diisi.
  8. Rate limit /auth/forgot dan /setup_admin tidak pernah berlaku. Token bootstrap dikirim di query string (masuk log).
  9. Reset password tidak di-route; /api/affiliate/link menghasilkan ref=false (variabel salah di affiliate.rs:202).
  10. Inbox federation tidak mewajibkan header Date dan Digest ikut ditandatangani.
