Konversi Harga Rupiah ke Polygon

Apakah harga dalam rupiah diterjemahkan ke dolar AS lalu ke jumlah token di jaringan Polygon? Sekarang ya. Bagian awal menjelaskan mekanisme yang berjalan setelah perbaikan 9 Nov 2026. Bagian “Analisis sebelum perbaikan” dipertahankan sebagai catatan temuan.

Ringkasan

Jawaban singkat

Rupiah → USD?Ya

Kreator bisa memasang harga dalam rupiah. Server menyimpan price_idr dan menurunkan price_cents dari kurs live, dibulatkan ke atas.

USD → Rupiah?Ya, dipakai menagih

Midtrans dan Xendit menagih rupiah bulat: harga rupiah persis, atau price_cents × kurs. Kurs diambil otomatis dan bisa di-override admin.

USD → token Polygon?Ya

Stablecoin 1:1. Token native (POL) memakai harga oracle CoinGecko yang segar (≤ 10 menit) dan dibulatkan ke atas; tanpa harga segar token disembunyikan.

Tagihan terlihat sebelum bayar?Ya

watch.html menampilkan Rp di tombol Midtrans/Xendit dan jumlah token di tab x402.

Arsip

Analisis sebelum perbaikan

Bagian berikut (rupiah, token Polygon, contoh angka, temuan gateway, rancangan, sumber kurs, perubahan data) menggambarkan kode sebelum 9 Nov 2026 dan rancangan yang kemudian diimplementasikan. Lihat tabel status di bagian “Status implementasi”.

Detail

Rupiah: hanya tampilan

Endpoint GET /api/kurs mengembalikan {usd_to_idr} dari variabel env. Halaman index.html, browse.html, watch.html, dan wallet.html memakainya untuk menampilkan harga rupiah:

// public/browse.html
const priceTxt = 'Rp ' + fmt.format(Math.round(v.price_cents / 100 * USD_TO_IDR));
  • Kurs tidak berubah sampai env diubah dan aplikasi di-restart. Halaman admin settings hanya menampilkan kurs, tidak bisa mengubahnya.
  • Rupiah yang dilihat pembeli bisa berbeda dari jumlah yang benar-benar ditagih, karena penagihan tidak memakai kurs ini (lihat temuan gateway fiat).
Detail

USD ke token Polygon

Di x402_start (src/handlers/pay.rs), jumlah token dihitung hanya dari harga dan jumlah desimal token:

// src/handlers/pay.rs
let token_amount_wei: u128 = if price_cents <= 0 { 0 } else {
    let numerator = (price_cents as u128).saturating_mul(10u128.pow(decimals));
    numerator.saturating_add(99) / 100   // dibulatkan ke atas
};

Artinya jumlah_token = price_cents / 100, yaitu 1 token dianggap bernilai tepat 1 USD. Nilai ini disimpan sebagai required_amount_wei, ditandatangani admin sebagai minAmountWei, lalu ditegakkan oleh kontrak X402Splitter.

Rancangan konversi yang benar

Prinsipnya: satu harga acuan, kurs diambil dari sumber tepercaya, lalu dikunci per invoice (kurs, sumber, dan waktu disimpan) agar bisa diaudit dan direkonsiliasi.

Rumus

// harga rupiah ke USD
usd_cents = round(price_idr / kurs_usd_idr × 100)

// USD ke stablecoin (USDC, d = 6)
units = ceil(usd_cents × 10^d / 100)

// USD ke token native (POL, d = 18)
units = ceil(usd_cents / 100 / harga_token_usd
             × (1 + buffer) × 10^d)

// USD ke rupiah untuk Midtrans / Xendit
amount_idr = round(usd_cents / 100 × kurs_usd_idr)

Contoh: harga Rp 170.000, kurs 17.000, POL $0.25

usd_cents   = 170000 / 17000 × 100   = 1000  ($10.00)
USDC        = 1000 × 10^6 / 100      = 10.000.000 unit (10 USDC)
POL (+1%)   = 10 / 0.25 × 1.01       = 40.4 POL
            = 40.400.000.000.000.000.000 wei
Midtrans    = 1000 / 100 × 17000     = Rp 170.000

Jalur termudah dan paling aman untuk Polygon adalah hanya menerima stablecoin USD (USDC/USDT). Dengan begitu tidak perlu oracle harga token, hanya kurs USD/IDR untuk tampilan dan untuk harga yang diinput dalam rupiah.

ISO/IEC 27001:2022 · regulasi

Regulasi & kepatuhan

Bukan nasihat hukum. Poin di bawah perlu dikonfirmasi tim legal sebelum pembayaran kripto atau konversi kurs diaktifkan untuk pengguna Indonesia.

  • Transaksi pembayaran di Indonesia wajib memakai rupiah, dan aset kripto bukan alat pembayaran yang sah. Menawarkan harga rupiah yang dibayar dengan token berisiko secara regulasi.
  • Kurs yang dipakai menagih harus transparan bagi pembeli dan tercatat per transaksi (jejak audit, A.8.15; integritas informasi, A.5.33).
  • Sumber kurs eksternal adalah pemasok; tetapkan SLA, fallback, dan perilaku saat data basi (A.5.19–A.5.22).
  • Kesalahan satuan pada gateway fiat berdampak langsung ke konsumen dan pendapatan kreator; perbaiki dan uji sebelum produksi (A.8.29, pengujian keamanan dan fungsi).
